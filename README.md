## 🔨 代表项目

**电商系统**（全栈 + 基础设施）
- 后端：Spring Boot + MyBatis-Plus + Spring Security(JWT) + RabbitMQ（异步订单）
- 前端：Vue3 + Vite + Element Plus
- 部署：kubeadm 自建 3 节点 k8s 集群，前后端 + MySQL/Redis/RabbitMQ 全容器化
- CI/CD：GitHub Actions 自动构建镜像（Jib，无 Docker daemon 环境）并滚动部署
- 监控：Prometheus + Loki + Grafana 监控栈、数据库定时备份
